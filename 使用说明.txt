职途 AI（手机内网求职版）

手机直接使用：
1. 电脑和手机连接同一个 Wi-Fi。
2. 在电脑双击“启动手机内网版.bat”，保持窗口运行。
3. 电脑窗口会显示一个地址，手机和电脑连接的同一 Wi-Fi 下，在手机浏览器打开 http://192.168.x.x:8081（或窗口列出的地址）。不要输入 127.0.0.1；它只代表手机自己。
4. 进入“职位”，填写岗位、专业技能、学历、地点和作息偏好，再选“五百强 / 外企 / 国企事业单位”搜索。
5. 也可以把“职途AI-手机直接打开.html”发送到安卓手机，用浏览器打开；若手机浏览器限制本地文件，使用同 Wi-Fi 地址方式。
每次程序更新后，手机端需要重新下载/接收最新版 HTML 文件；原先保存到手机的旧副本不会自动更新。

使用方式：
电脑单机使用：双击“打开职途AI.bat”，不要直接双击 HTML 文件。程序会自动打开 http://127.0.0.1:8080。

手机内网使用时，页面和个人填写内容由本机提供；搜索按钮会在 Edge 中打开 Bing，需要可访问互联网，但不需要 VPN。应用页面本身不展示广告；搜索结果页的推广位由搜索服务管理。
手机 Edge 可在“菜单 ⋯ > 设置 > 隐私和安全 > 内容拦截器”开启“阻止广告”；如需屏蔽全部广告，关闭“允许可接受的广告”。
如果手机打不开地址：确认电脑上的黑色服务窗口仍在运行；手机和电脑连同一 Wi-Fi（访客 Wi-Fi 可能禁止设备互访）；若 Windows 防火墙询问，请允许 Node.js 在“专用网络”通信。修改页面后，关闭旧服务窗口，再重新运行启动脚本。
可用手机浏览器的“添加到主屏幕”生成桌面图标。电脑需要保持开机并运行服务。

姓名和“加入投递”的职位只保存在当前手机/电脑浏览器中。

隐私说明：
- 当前版本不会上传姓名、简历或职位记录。
- 页面中的职位与 AI 分析结果为交互演示数据；搜索结果来自外部搜索引擎，投递状态请以企业官网为准。
- 若后续要抓取公众号招聘，需要单独配置内网采集服务，并取得内容授权、遵守平台规则。

建议：
将整个 jobpilot-ai 文件夹复制给使用者，不要只复制 bat 文件。
