# 职途 AI 求职助手

一个适合手机和电脑使用的中文求职助手原型。界面可离线打开；企业招聘检索会在浏览器中打开 Bing 搜索结果。

## 功能

- 编辑简历并实时预览，内容自动保存在当前浏览器。
- 按岗位、技能、地点、学历、工作时间和待遇偏好生成多条招聘搜索入口。
- 预置增城及广州周边企业招聘入口，以及广东公共招聘、国聘和增城区政府招聘页面。
- 支持打印或导出简历为 PDF。

## 在电脑上运行

需要安装 Node.js，并确保 `node` 命令可用。

- 双击 `打开职途AI.bat`，只在本机打开。
- 或在项目目录运行 `node server.mjs`，再访问 `http://127.0.0.1:8080`。

## 在手机上运行

1. 电脑和手机连接同一个 Wi-Fi。
2. 在电脑双击 `启动手机内网版.bat`，并保持窗口运行。
3. 在手机 Edge 或其他浏览器打开窗口显示的局域网地址（端口 8081）。

手机无法直接访问电脑上的 `D:\` 文件。局域网方式要求电脑开机并运行服务；访客 Wi-Fi 可能禁止设备互访。

## 构建独立手机文件

运行 `node build-single.mjs`，生成 `职途AI-手机直接打开.html`。将这个 HTML 文件发送到手机后，用浏览器打开。每次更新后，需要重新发送最新版。

## 数据与搜索说明

- 简历只存储在当前设备浏览器的本地存储中，不会上传到此项目或 GitHub。
- 搜索入口根据填写条件生成 Bing 查询，实时结果由 Bing 提供；本项目不爬取或抓取招聘网站、企业官网或微信公众号。
- 项目内的示例职位仅供界面演示，不代表当前真实招聘。
- 应用本身没有广告。搜索服务可能显示自己的推广结果；手机 Edge 可在“设置 → 隐私和安全 → 内容拦截器”开启广告拦截。

## GitHub 与手机访问

私有 GitHub 仓库适合给家人授权查看源码，但 GitHub Pages 不适合默认作为家庭私密访问入口：个人免费计划的 Pages 需要公开仓库；而私有 Pages 访问控制需要 GitHub Enterprise Cloud。若只想让家人用手机访问，请优先使用同一 Wi-Fi 的内网方式，或另行配置带登录保护的托管服务。

项目没有第三方运行时依赖。默认招聘链接和页面文案可按需要修改。
